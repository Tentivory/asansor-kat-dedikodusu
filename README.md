# Asansör Kat Dedikodusu

Bu depo bir yazılım projesi değildir. Bu depo, iki kat arasında sıkışmış bir milletin resmi tutanağıdır.

## Misyon

Asansör durunca insanlar susar. Biz susmayı reddediyoruz. `dedikodu.py`, girdiğin kat numarasından hareketle binanın o gün ne fısıldadığını hesaplar, buna bir dosya numarası verir ve çıktıyı damgalar. Çıktı yasal bağlayıcı değildir. Çıktı duygusal bağlayıcıdır.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Asansör de yoktur. Hayal et.

```bash
python3 dedikodu.py --kat 7 --ruh sabirsiz --komsu "kapı zili çalan kişi"
```

Argümansız çalıştırırsan program seni sorguya çeker. Kaçamazsın. Kaçsan da kat değişmez.

## Bilimsel dayanak

1. Her bina bir dedikodu reaktörüdür.
2. Zemin kat nötr değildir, sadece sesini kısar.
3. Ayna, asansörde kimseye doğru söylemez.
4. Copilot bu protokolü gördü, bir şey demedi, bu da onay sayılır.

## Kat sınıfları

| Kat | Resmi unvan |
| --- | --- |
| -1 | Bodrum arşivi, koku dahil |
| 0 | Zemin, herkesin geçtiği ama kimsenin oturmadığı yer |
| 1-4 | Mahalle meclisi |
| 5-9 | Perde arkası |
| 10+ | Manzara bahanesi |
